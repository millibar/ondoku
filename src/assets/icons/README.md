# assets/icons/

UIアイコン用のSVGファイルを置くディレクトリ。参照: docs/spec.md 4.1節・4.2節

以下の4つをSVGアイコン化する予定（ファイルはユーザーが用意する）。ファイル名は下記を想定しているが、実際に用意されたファイル名に合わせて実装時に調整する。

- `shuffle.svg`: ランダム再生トグル（練習画面）
- `repeat-one.svg`: 1リピート再生トグル（練習画面）
- `favorite-filter.svg`: お気に入りのみ表示トグル（練習画面）
- `favorite.svg`: お気に入りに追加／解除ボタン（練習画面・英文選択画面で共通）

トグル・ボタンのON/OFF状態は、アイコン画像自体を切り替えるのではなく、既存の`ContentText.tsx`の`EyeIcon`と同様にCSSの`data-*`属性等で色を切り替える想定（1ファイルで済ませる場合）。ON/OFFで見た目を大きく変えたい場合は、状態ごとに別ファイル（例: `favorite-filled.svg`）を用意してもよい。
